# 对 FDE 的认识

自从接触 FDE，我听到了很多人对它的看法和解读，有人说它是驻场外包，有人说它是全栈工程师。

在听了曹犟老师的课程后，我对他的 FDE 定位印象深刻。

**“所谓 FDE，其实就是一个嵌入客户现场、主动交付有价值结果的产品探索者。”**

这句话要分成三个部分来理解。

#### 一、嵌入客户

需求不是坐在办公室想出来的，也不是打几个电话听客户吐槽听出来的，是要陪在客户身边，真正下场实验试出来的。

*这个时候和外包同学确实有点像~*

#### 二、主动交付有价值的结果

主动定义客户的问题是什么，并且探索适合帮助客户解决问题的产品形态。

*加上这个也只是像个驻场开发工程师。*

#### 三、产品探索者

这是 FDE 最硬的内核，他的最终目标绝不是只服务好客户，而是在解决用户问题的同时，探索一套通用的产品能力。

所以 FDE 是**在帮客户解决问题中沉淀自己的产品的人**。

## 和其他职业的区别

|              | FDE                                          | 咨询 | 外包                                   | 驻场           | 售前         |
| ------------ | -------------------------------------------- | ---- | -------------------------------------- | -------------- | ------------ |
| 交付的产品   | 具体的，还未成形的系统                       | 报告 |                                        | 已经存在的产品 |              |
| 产品方向     | 自己建议并决定                               |      | 听甲方指挥                             |                |              |
| 产品形态沉淀 | 越来越厚<br />服务第二家的时候比第一家要容易 |      | 无产品沉淀<br />服务几家公司周期都一样 |                |              |
| 最终目标     | 交付对客户有价值的产品                       |      |                                        |                | 把东西卖出去 |

其实对照上面的表格大家可以看到，FDE 也可以从五个标准上判断

1. 薪资是否存在提成
2. 是否存在自己的产品沉淀
3. 服务客户难度阶梯型递减
4. 是否有已存在的系统
5. 对什么负责

由此可知，FDE 对标传统的 IT 外场人员还是有明显区别的，且 FDE 更像是从前整个驻场定制化开发的团队，只是现在借助 AI，这个团队变成一两个人了，并且在开发完成之后，有一部分经验是要回流到自己的产品中的，直到这个产品足够健壮，再以业内通用软件的方式，售卖给行业内的公司。
