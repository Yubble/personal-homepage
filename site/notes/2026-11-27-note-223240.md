# Harness 架构是什么

要说 Harness 的话，就要讲到智能体的起源了~

早期 ChatGPT 刚火起来的时候，无所不知，而且不是纯靠查资料，扒网页信息，人家有推理能力的，这时候就有了个**大脑**，外加耳朵和嘴。

但是只有这三样满足不了人类的需要，它不能只当个顾问，也要能干活啊，顺势 Agent 就诞生了。

Agent 是长了手脚的 AI，它可以调用工具去完成工作的，比如 Manus，以及其他一系列影音智能体。

这些智能体虽然算不上特别好用，但是绝对让 AI 进步了一大截，人们发现只要给 AI 配上工具，它们真的能代**替我们干活**。

但是这个过程中问题也出现了，AI 会出现幻觉，错误的调用工具，它在解决某些问题的同时需要借助远程的工具，有时推理出现偏差，如果自省则容易钻牛角尖，更可气的是 AI 没记忆，第一句没说完，再说就记不得了。

最最最可怕的是 26 年初火过一阵的 OpenClaw，它的权限太大了，把账号给它它真敢给你花钱。

## Harness 的前世

harness 这个词作为技术词汇不是在 Agent 时期创建的，它早期是用来做评测的。每次测试大模型都会将其进行约束，控制输入输出，对比预期。

后来发现将这个思想用在“约束大模型进行标准化运营”的思路是一样的，就把它沿用过来了。

harness 本意是马具，不是套在马背上的马鞍哈，是套嘴上的....。含义就是给一个力量很大，不受控制的对象套上枷锁，让它在可控的条件下干活。

而早期的 Agent 也有明显不可控的特点

* 运行时不可靠，token 被肆意烧光
* 长任务里上下文爆炸，不会自己压缩，也无法自己派生子 agent 干活
* 安全！改文件，发请求，得有审批啊

所以 harness 并不是某种特指的技术，它是一种设计思想，工程中对它有种说法叫做“骨架”，这让我想起了一个经典公式

> Agent = Harness + Model

## Harness 的今生

现今 harness 已有了清晰的核心能力清单。大致如下：

#### 控制循环(loop)

经常关注 AI 的朋友应该会听过 ReAct，是由模型思考、行动、观察，再思考的一种循环工作方式，目的是自我检查，拿到最优答案之后再回复或最终行动。

但注意这里决定是否达到最优解，可以循环结束是由模型来决定的，所以这里是会失控的一个点，也就引发了 Loop Engineering 这个设计思路，来定义循环的停止条件（最大循环数，任务完成）。

#### 工具层

* 注册 schema（告诉模型我有哪些工具，现在的模型厂商都有 tools schema 的直接通道）
* 调度与执行（把模型输出的调用请求翻译成真实操作）
* 支持**MCP、A2A** 这类协议（能跨应用通信）

#### 上下文管理

* 把逐渐庞大的上下文进行摘要、压缩、剪裁。（先用代码实现，达到一定体积后再用模型进行压缩摘要）
* 按需检索代码或文档。用工具的描述加函数调用，让大模型准确地在庞大的信息库中找到需要的内容进行回复。
* 上下文**注入**（system prompt、任务状态、历史摘要的组装）

#### 记忆与状态

* **短期**：当前对话/任务的历史/近几轮对话（不会存在磁盘）
* **长期**：跨会话的经验、偏好（向量库/文件存储）
* **任务状态持久化**：中断了能接着干，不丢进度

#### 规划与编排

* 把大任务**拆解**成子任务（根据业务特点设计图流程）
* 开**子代理（sub-agents）**、并行 worker、多代理协作。（Codex 和 Claude Code 的典型做法）

#### 执行环境

* Shell / 沙盒 / 文件系统的访问
* 环境隔离（防止 agent 把系统搞坏）
* **Human-in-the-loop**，危险操作需要有人来确认

CC 和 Codex 并发隔离都使用 worktree，将有风险的代码放在分支目录中修改并运行推演，并且它能通过 tree-sitter 解析，能认识危险语句，及时停止并进行人机确认。

权限隔离是系统原生沙箱路线，控制网络，并通过代理进行本地访问。

#### 验证反馈

这是编程类 Agent 的命脉。

* 跑测试、linter、类型检查
* 把结果**喂回模型**，驱动自我纠错，没有这层，agent 只能"盲写"

这就是典型的 ReAct。

#### 可观测与恢复

* 日志、trace
* checkpoint / 回滚
* 断点续跑、失败重试

这些都是编排型框架需要具备的能力，主要是节点（checkpoint）。

#### 模型抽象

* 多模型切换、路由（简单问题用便宜模型）
* 重试、降级、超时处理

以上就是我整理的 harness 知识图谱大全了，断断续续地整理了两天，总算是把这块知识补上了。
